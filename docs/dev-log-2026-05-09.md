## 3. 钱包绑定永久卡死 Bug 修复（关键）

### 问题描述

Telegram 用户在 TMA 内绑定钱包时，若该钱包已被其他账号占用：
1. 前端显示"Update wallet failed"报错
2. 之后无论重新连接哪个钱包，**永远失败**，页面永久卡死，只能关闭 TMA 重进

### 根本原因

**双层缺陷：**

**① `TmaWalletBinder.tsx` — `handledRef` 未在失败时清除**

```ts
// useEffect 去重守卫
if (handledRef.current === address) return
handledRef.current = address   // ← 失败前已设
saveWallet(address)

// 旧 saveWallet：catch 没有清除 handledRef
catch (err) {
  setStatus('error')
  setError(...)
  // handledRef.current 依然是旧地址！
  // 下次 useEffect 触发时 address 相同 → 直接 return，永不重试
}
```

**② `bind-wallet/route.ts` — 唯一约束冲突与真实 DB 错误未区分**

所有数据库错误均返回相同的 `update_failed`，前端无法识别"钱包已被他人占用"与"服务器故障"的区别。

### 修复方案

**`app/api/profile/bind-wallet/route.ts`：**
```ts
if (error) {
  console.error('bind-wallet error:', error)
  if (error.code === '23505') {   // Postgres 唯一约束冲突
    return NextResponse.json({ error: 'wallet_taken' }, { status: 409 })
  }
  return NextResponse.json({ error: 'update_failed' }, { status: 500 })
}
```

**`components/wallet/TmaWalletBinder.tsx`：**
```ts
} catch (err) {
  handledRef.current = null   // ← 关键：解锁，允许重试
  setStatus('error')
  setError(err instanceof Error ? err.message : 'save_failed')
}
```

错误 UI 增加专属提示和操作按钮：
```tsx
{error === 'wallet_taken'
  ? 'This wallet is already bound to another account. Please connect a different wallet.'
  : 'Failed to save wallet. Please try again.'}
{error === 'wallet_taken' && (
  <button type="button" onClick={handleReset} ...>
    Try a different wallet
  </button>
)}
```

### 修复后行为

| 场景 | 修复前 | 修复后 |
|------|--------|--------|
| 绑定已被占用的钱包 | 卡死，永远失败 | 显示"钱包已被占用"，提供"Try a different wallet"按钮，点击后可重新选择 |
| 绑定成功 | 正常 | 正常 |
| DB 真实错误 | 同上报错 | 显示"Failed to save wallet"，可重试 |
