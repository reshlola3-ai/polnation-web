## 三、管理员端 Tasks 问题分析

### 问题一：审核通过后奖励未发放到用户

**根本原因：** `app/api/admin/tasks/route.ts` 的 `review` action 使用了 `upsert` 但未指定 `onConflict: 'user_id'`。

**Bug 流程：**
1. 管理员批准任务（如 YouTube 视频，$50）
2. 代码读取用户现有 `user_task_progress` 记录
3. 执行 `upsert({ user_id, total_task_bonus: existing + 50 })`，但没有 `id` 字段
4. Supabase 默认按主键 `id` 冲突检测，由于无 `id`，尝试 INSERT 新行
5. `user_id` 唯一约束触发冲突 → INSERT 失败
6. 代码未检查 error → **静默失败**
7. $50 从未写入数据库

**对比：** 用户端 `updateTaskProgress` 函数正确使用 update/insert 分支，管理员端没有沿用。

**修复：** 将 upsert 改为显式 `if (progress) { update } else { insert }` 模式。

**文件：** `app/api/admin/tasks/route.ts`，commit `d5dd57fd`

**数据补救：** 在 Supabase SQL Editor 手动执行：
```sql
UPDATE user_task_progress
SET total_task_bonus = total_task_bonus + 50,
    updated_at = now()
WHERE user_id = '27d16c07-fbcc-4094-87a0-bc0f048d51d4';
```

## 十、Mobile-First 重设计（去 AI 感）

### 背景与诊断

用户反馈前端"AI 感太重，不够现代简洁"，移动端体验差。调研 Coinbase 2026 redesign、MetaMask dark mode 4.2.0、Trust Wallet 移动端设计规范后，识别出以下核心问题：

| 问题 | 表现 |
|------|------|
| 过度 Glassmorphism | 多层 `backdrop-blur(20px)` + `bg-white/10` 叠加，2026 年已被视为 AI 生成模板特征 |
| 信息密度过高 | 首屏需 3-4 次完整滚动才能看完所有内容 |
| 字号过小 | 大量 `text-[10px]`/`text-[11px]`，移动端户外环境无法阅读 |
| 动画过重 | 3 层 framer-motion 循环渐变 + 全屏星星闪烁 + 光球浮动，耗性能且显眼 |
| 颜色杂乱 | 次要文字颜色超过 8 种（purple-200/300、zinc-400/500、white/40/50/60/70 混用） |
| emoji 做图标 | 🏆🌐✅🔥 等 emoji 作为功能图标，不专业 |

### 设计原则（来源：Coinbase/MetaMask 2026）

1. **实色 > 模糊** — 卡片用纯深色实色，完全去除 backdrop-blur
2. **最小字号 12px** — 消灭 text-[10px]/text-[11px]
3. **首屏只放 3 件事** — 余额、主 CTA、当前状态（参考 Trust Wallet）
4. **统一圆角 12px** — CSS variable `--radius-card: 12px`
5. **Lucide icons 替代 emoji** — 统一图标语言
6. **移动端关闭所有动画** — 降低耗电，提升流畅感
