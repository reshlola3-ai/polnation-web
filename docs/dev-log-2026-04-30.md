## 第 1 部分：polygon-clone 手机端修复

`/` 的渲染源是 [public/polygon-clone/index.html](../public/polygon-clone/index.html)（运行时由
[middleware.ts:5-7](../middleware.ts) rewrite），里面用一段 inline `<script>`
做静态 HTML → polnation 改造。这一节修了 5 处手机端可见缺陷。

### 1.1 BENEFITS 区段 — 误删自建分叉，改用 polygon 原生 Swiper

**背景**：之前有一套 `.polnation-benefits-mobile-*` 自建轮播 CSS + JS（约 276 行），
和 polygon.technology 视觉差异显著（文案消失、卡片溢出、缺右上角 notch）。

**第一次尝试（commit [`0d504af9`](../public/polygon-clone/index.html)）**：
把整套自建分叉删掉，假定 polygon 手机端是"列堆叠"。**这个假设错了** ——
实际渲染显示单张超大卡，比之前更糟。

**根因发现**：直接 `curl https://polygon.technology/` 抓真实 HTML，发现 polygon 用的是
**Swiper.js** 横向轮播：

```
.purpose-mobile-slider-container
  .purpose-slider.swiper
    .purpose-list.swiper-wrapper
      .purpose-slide.swiper-slide  (×6)
        .h-feature-card  (mobile feature-card-bg viewBox 253×240)
  .purpose-pagination
    .purpose-static-dot / .purpose-active-dot
```

而且 polygon.css 早就把所有这些 class 都样式好了，Swiper.js 也已经在
[index.html:1692](../public/polygon-clone/index.html#L1692) 通过 CDN 加载。
之前自建分叉是从零造轮子。

**最终修复（commit [`6016e4eb`](../public/polygon-clone/index.html)）**：
- 加最小断点 CSS（手机端隐藏 desktop grid，桌面隐藏 swiper）
- 在 `applyFeaturedSection()` 里注入 polygon 原生 swiper DOM
- `new Swiper(...)` 初始化，配置 `bulletClass: 'purpose-static-dot'` /
  `bulletActiveClass: 'purpose-active-dot'` 让 dot 用 polygon 原生样式

### 1.2 Logo 在手机端"低 + 小" — commit [`ed640116`](../public/polygon-clone/index.html)

**根因**：[index.html:1969-1976](../public/polygon-clone/index.html#L1969-L1976)
`.polnation-nav-brand img` 的桌面 `transform: translateY(8px)` 在手机端没被 override，
继续把 logo 推下去 8px；高度 32px 也比 GET REWARDED 按钮（≈44px）矮一截。

**修复**：手机端媒体查询加 `transform: none` + `height: 40px`。

### 1.3 二级菜单 dead taps — commit [`d419aa24`](../public/polygon-clone/index.html)

**根因**：Webflow 静态 HTML 里 `.nav-dd-card` 这些 `<a>` **完全没有 `href`**。
polygon.technology 上 Webflow 路由在运行时注入，静态克隆里没注入，所以变成 dead anchor。

**修复**：在 `applyStaticCopy()` 里加 `wireDropdownLinks()`，按卡片标题文字注入 href，
并加 click handler 关闭手机端折叠菜单（hash 跳转不会触发 reload）。

映射规则：
- "Academy" / "Academy Guide" / "Agentic Wallet Academy" → `/academy`
- "Rewards Hub" / "Join Polnation" / "Polnation Wallet" → `/dashboard`
- 其他全部 → `/#polnation-benefits`（首页 BENEFITS 锚点）

### 1.4 Withdraw 数字在手机端被压成 16px — commit [`b8da9957`](../app/(dashboard)/earnings/page.tsx)

**根因**：[globals.css:1010-1020](../app/globals.css#L1010-L1020) 的 iOS-zoom
防御规则强制所有 `input[type="number"]` 在 ≤768px 下 `font-size: 16px !important`，
覆盖了 [earnings/page.tsx:515](../app/(dashboard)/earnings/page.tsx#L515) 的
`text-[64px]`。结果 `$` 字符（30px）反而比数字（16px）大。

**修复**：用 Tailwind v4 的 `!important` 后缀语法 `text-[64px]!`，单点覆盖。
未来如再出现可考虑改 globals 的根因写法（`:where(:not([class*="text-["]))` 之类）。

## 第 2 部分：dashboard 设计系统对齐 polygon（commit [`f1c15e80`](../components/ui/poly/))

### 背景与诊断

dashboard 当前是 "Kraken / Apple Wallet" 风格（圆角卡 + 渐变 + 光晕），
polygon.technology 是"工程感 + 缺角几何 + Mono 字体"风格。两者**视觉语言根本不同**，
靠局部调色补不上。

视觉差异维度对比：

| 维度 | polygon.technology / 首页 | dashboard 当前 |
|---|---|---|
| 卡片轮廓 | **缺角矩形**（`.feature-card-bg` SVG，左上 + 右下被斜切） | 普通圆角 `rounded-2xl` |
| 字体 | Polysans + Polysans Mono 双字体 | 默认 sans-serif |
| 标签字体 | mono caps + `tc-g200` 灰，作为 eyebrow | 普通 caps + tracking |
| 数字 | mono 字体 + `tabular-nums` | tabular-nums 但默认字体 |
| 主紫 | `#670de5`（polygon purple） | `var(--kraken-purple)` 不同的紫 |
| 背景 | 浅灰 `#f2f1f5` 或纯黑 `#07060d`，flat | `#0D0B21` 深紫底 + 紫/青光晕 blobs |
| 按钮 | clip-path 缺角 | rounded pill |
| eyebrow | 双三角 SVG bracket 包住 caps mono 文字 | 没有 |
| 强调 | `tc-g200` 把次要词降灰，flat 不发光 | 渐变 + 发光 blur |

### Phase 0 — 设计 tokens（已完成）

[globals.css:59-83](../app/globals.css#L59-L83) 把旧 `--poly-*` 变量
（值都对不上 polygon）替换成 polygon.technology 真实的 `--swatch--*` 值：

```css
--poly-purple: #670de5;
--poly-purple-hover: #721fe5;
--poly-grey-200: #888a91;
--poly-inverted-primary: #f2f1f5;
--poly-inverted-primary-dark: #07060d;
/* ...等 */
```

**视觉变化：0**（旧变量没被任何代码引用，纯换值）。

### Phase 2 — 三个 React 原子组件 + dashboard PoC（已完成）

新建 [components/ui/poly/](../components/ui/poly/)：

1. **`<NotchedCard>`** — 包 polygon 的 `.feature-card-bg` SVG 路径
   （viewBox 253×240，左上 + 右下倒角），`vectorEffect: non-scaling-stroke`
   避免拉伸变细。
2. **`<EyebrowTag>`** — mono caps 小标签（用 `--poly-font-mono` + `--poly-grey-200`），
   对标 polygon 的 `.u-mono-medium tc-g200 all-caps`。
3. **`<MonoStat>`** — PolySansMono 大号数字，可选 `$` 前缀（小一号、白 55%）和
   suffix（"POL" 之类）。`size: 'tile' | 'main'` 两档。

应用到 dashboard 的 WALLET / WITHDRAWABLE / TEAM POOL 三联卡（Phase 2 PoC）。
保留 loading skeleton、help tooltip、`/earnings` link 行为，只换视觉皮肤。

## 取舍记录

- **不要 import 整个 polygon.css**（534KB minified，和 Webflow class 强耦合）。
  只抽变量 + `@font-face`。
- **不要直接抄 polygon.technology 的视觉密度**（营销页布局比 dashboard 宽松得多）。
  策略是**结构借**（缺角卡、eyebrow、mono 数字、purple `#670de5`）但**密度变**
  （dashboard 卡片小一倍、padding 收紧）。
- **glow blob 全删**（Phase 3 时一并清理） —— 这是当前 dashboard 跟 polygon
  最不像的元素，但删要找时机不要单独动。
- **保留所有现有交互逻辑**（loading skeletons、tooltip handlers、Link 跳转、
  i18n keys）—— 重构只改视觉皮肤。
